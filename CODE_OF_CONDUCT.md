# Code of Conduct

RxyCode's GitHub Issues, Discussions, and pull requests are a public workshop.
Be direct, stay on the topic of the project, and do not share secrets.

## Expected

- Argue about the work, not the person.
- Search before opening a duplicate Q&A or issue.
- Redact API keys, tokens, and private file contents from logs.
- Use [Discussions](https://github.com/xin-yi33/RxyCode/discussions) for questions and ideas; use Issues for reproducible bugs.

## Not allowed

- Harassment, hate, or sexualized content.
- Spam, advertising unrelated to RxyCode, or scraped dump posts.
- Posting other people's private data.

## Enforcement

Maintainers may edit, lock, or delete posts and block accounts that break this
policy. Report a private incident to the repository owners through GitHub
(do not open a public issue that repeats the abuse).

This policy applies to `xin-yi33/RxyCode` spaces on GitHub.
