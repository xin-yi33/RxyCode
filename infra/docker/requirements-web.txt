# W10-D1: pinned dependency set for the production api + worker images.
#
# Provenance: union of the `pip install` lists the compose services used to run
# at every `up` (api: fastapi/uvicorn[standard]/sqlalchemy/alembic/psycopg/
# httpx/pydantic/boto3; migrate: sqlalchemy/alembic/psycopg; worker: the repo
# requirements.txt), resolved to the exact versions the running `rxydemo`
# containers report via `pip freeze` (api and worker, 2026-10-20). Pinning the
# full transitive closure — not just the direct requirements — keeps the image
# builds reproducible even when PyPI publishes a newer transitive release.
#
# Deliberate exceptions:
#   - rxycode-runner is NOT pip-installed; like the compose stack it is a
#     source package placed on PYTHONPATH (/repo/packages/*/src).
#   - websockets is pinned to 16.1.1 (the worker container's version): the
#     api container ran 17.3, but a langgraph-sdk bound caps the union set
#     below 17 — uvicorn[standard] accepts 16.x for the api's WS surface.
#   - pywinpty stays out: it is Windows-only (requirements.txt env marker) and
#     these images are Linux.
