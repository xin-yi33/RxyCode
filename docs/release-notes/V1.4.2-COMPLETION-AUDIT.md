## Fixes made in this audit

The source, worker and test fixes below were implemented by GPT-5.6 Luna
(xhigh) and independently checked by the release owner. Packaging and product
metadata were handled by the release owner.

1. `core/agent_v2.py`/`core/prewarm.py`: prewarm uses one parent task with two `gather()`
   children. A child previously cancelled its own parent through
   `_raw_stream`, causing recursive asyncio cancellation and `RecursionError`.
   a per-task prewarm `ContextVar` now protects archive streams, and
   `_cancel_background_prewarm()` refuses to cancel the current task while
   preserving cancellation for a concurrent real user turn. The regression
   test exercises both archive-child isolation and user-turn cancellation.
2. `appserver/agent_worker.py`: worker stdio is explicitly reconfigured to
   UTF-8 before the RPC reader starts. Setting `PYTHONIOENCODING` after Python
   created the streams was too late on locale-bound Windows pipes; non-ASCII
   prompts could become surrogate code points and fail checkpoint identity
   hashing before the scripted/real model request.
3. `tests/conftest.py`: class-form setuptools `_EditableFinder` is now removed
   correctly (`type(finder).__name__` is only `"type"` for this form), and
   stale canonical/bare modules from another checkout are purged before the
   current checkout is bound.
4. The FIX5 worker restart test uses a synthetic `api_key_env` model config,
   disables team/subagent routing, and never copies the developer's real
   `config.yaml` or `credentials.yaml`.
5. The P8 fixture import was corrected from the nonexistent
   `protocol.todo_snapshot` to `protocol.todo`; no compatibility alias module
   or production P8 consumer was added. Four known ruff unused variables were
   renamed with underscore prefixes without removing their side-effecting
   schedule/send calls.
6. The three historical Phase P red tests were corrected as test contracts only:
   P02 now binds the synthetic agent to an explicit session and the current
   run id, checks the pipeline ledger under `(session, run)`, and awaits every
   canceled fake task; P06 uses a below-cap tool budget for its two legal
   concurrent model decisions and adds an exact-cap zero-LLM policy-stop case;
   P09 uses explicit call ids, records the interrupt's fail-closed stop, checks
   that it grants nothing, and checks that the later successful round emits no
   new decision event. No production cap, ledger, or interruption rule changed.
7. The stale-editable subprocess regression now clears inherited xdist worker
   variables and receives its own `tmp_path`-based test root/run id, so the
   fail-closed root creation rule remains strict under `pytest -n2`.
8. The Windows ResumeThread failure fixture now mocks `_close_handle` and
   asserts `TerminateProcess`, wait, and all three expected fake-handle closes
   by numeric handle value. The old fixture mocked termination and waiting but
   let fake handles reach real `kernel32.CloseHandle`, which could close a
   pytest timer-thread handle and surface as `Failed joining thread`.
