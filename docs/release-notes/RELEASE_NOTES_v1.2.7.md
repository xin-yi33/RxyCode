# RxyCode v1.2.7

RxyCode 是一个规划-执行型的 AI 编程助手：把复杂任务自动拆解成子任务，通过安全工具编排器执行、验证结果后综合出最终答案，全程实时流式输出到终端界面。

> **推荐使用 v1.2.7。** 本版聚焦"完成的任务不再被误报失败"：修复了真实使用中"明明写好了文件 / 明明给出了完整回答，却被报成失败"的问题，并让联网搜索更聪明、思考型模型更稳定。

## 简要说明 / Summary

这一版是**可靠性修复版**：重点解决"任务其实完成了，结果却显示失败"这类最影响体验的问题。

- 修复：完成的回答不再被"某个网页没抓到"这类小失败覆盖
- 修复：联网搜索不再把整段指令当搜索词，搜索结果更精准
- 修复：DeepSeek 等思考型模型的思考内容正确回传，不再报 400 错误
- 新增：支持豆包（Doubao / ark）模型
- 修复：写了文件的任务不再因为回答里引用了一个没抓取的网址而整个失败

## 亮点 / Highlights

- **完成的任务不再误报失败** — 以前联网搜索时只要有一个网页抓取失败（比如某个链接 404），即使任务已完整完成、答案已生成，也会被整体标记为失败。现在只有真正关键的操作（写文件失败、命令执行失败）才会判失败，普通探测性失败不再影响结果
- **联网搜索更聪明** — 强制联网搜索时会自动从你的话里提炼出核心搜索词（比如你说"搜索成都三日游攻略"，实际搜索的就是"成都三日游攻略"，而不是整段话），搜索结果更准
- **思考型模型更稳定** — 修复了 DeepSeek 等思考型模型在多次工具调用时报"400 reasoning_content 必须回传"的错误，长任务不再中断
- **写了文件就承认成功** — 修复了"文件明明写好了，却因为回答里引用了一个没抓取的网址而整个报失败"的问题
- **新增豆包模型支持** — 可用豆包（Doubao）官方 API 作为模型后端

## 详细说明 / Details

### 修复的 Bug

- **完成的回答被误判失败（最关键的修复）** — 之前只要一轮对话里有任何工具调用被标记失败（例如 webfetch 抓取一个 404 链接、websearch 某引擎没返回结果），即使 agent 已经完整完成任务并生成了高质量答案，最终结果也会被替换成 `[evidence failed: ...]`。现在只对 **WRITE/DANGER 级工具失败**（如写文件、跑命令失败）和**产物校验失败**（文件写入但内容不对）做整体否决，只读探测类失败不再影响结果。
- **联网搜索词错误** — 强制联网搜索时直接把整段用户指令当作搜索词发给搜索引擎，导致返回垃圾结果。现在新增搜索词提炼逻辑，从指令中提取核心主题。
- **思考型模型 400 错误** — DeepSeek v4 等思考型模型要求：带工具调用的请求链路上，必须把上一轮助手消息的 `reasoning_content`（思考内容）原样回传，否则返回 HTTP 400。现在消息序列化时正确保留并回传该字段。
- **写文件任务被引用校验误伤** — "搜索并写一份攻略"类任务，文件已经写好，但 agent 在回答里引用了一个搜索列表里未成功抓取的网址，整个回答被判失败。现在**已产生实际交付物（写文件成功）的任务不再因此判失败**；纯问答场景仍严格校验引用，防止模型编造来源。

### 新增功能

- **豆包（Doubao）模型支持** — 新增 DoubaoProvider，适配火山方舟（ark）coding 端点，可与现有模型并列使用。

### 验证与回归

- 后端相关测试（research、evidence、工具契约等）全部通过
- 前端 Ink 界面与 OpenTUI 测试全部通过
- 5 个真实 Agent 冒烟任务（网页搜索、网页搜索+代码、网页搜索+游戏、网页搜索+旅游攻略、网页搜索+多步报告）全部成功完成并产出交付物

## 安装 / Install

**推荐（v1.2.7）：**

```powershell
# Windows
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/xin-yi33/RxyCode/v1.2.7/install.ps1 | iex"
```

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/xin-yi33/RxyCode/v1.2.7/install.sh | sh
```

```bash
uv tool install --force "git+https://github.com/xin-yi33/RxyCode.git@v1.2.7"
```

**下载策略：** 仅本页（v1.2.7）提供 wheel / sdist。更早版本的 GitHub Release **不开放**安装包下载。
