## 📋 项目目标

基于全面审查报告，本项目旨在通过以下6个月的系统性改进，将RxyCode从Tier 2（功能型产品）提升到Tier 1（生态型平台）水平。

**核心目标：**
1. ✅ 完成Desktop应用开发（MVP + 增强版）
2. ✅ 清理核心技术债务（AgentV2重构 + 循环依赖）
3. ✅ 实现差异化功能（Skills自动创建 + 消息平台集成）
4. ✅ 提升测试覆盖率（67% → 75%）
5. ✅ 建立企业级部署能力（Kubernetes + Helm）

## 🔄 开发流程

### Sprint规划（2周一个Sprint）

**Sprint周期：** 每2周

**Sprint仪式：**
- **Sprint计划会**（每Sprint第1天，2小时）
  - 确定Sprint目标
  - 任务拆分和估算
  - 承诺交付内容

- **每日站会**（每天，15分钟）
  - 昨天完成了什么
  - 今天计划做什么
  - 遇到什么阻碍

- **Sprint评审会**（每Sprint最后1天，1小时）
  - 演示完成功能
  - 收集反馈

- **Sprint回顾会**（每Sprint最后1天，1小时）
  - 讨论流程改进
  - 总结经验教训

### 代码质量标准

1. **代码审查（Code Review）**
   - 所有代码必须经过至少1人审查
   - 使用GitHub Pull Request
   - 审查清单：功能正确性、代码风格、测试覆盖

2. **自动化测试**
   - 单元测试覆盖率 ≥75%
   - 集成测试覆盖核心流程
   - E2E测试覆盖关键场景

3. **静态代码分析**
   - Python: Ruff + mypy
   - TypeScript: ESLint + TypeScript Compiler
   - 每次提交自动运行

4. **文档要求**
   - 所有公共API必须有文档字符串
   - 复杂逻辑需要注释说明
   - README保持更新
