# Support

RxyCode uses GitHub for all public support. Do not send API keys or other secrets.

| You need | Where |
|----------|--------|
| Install / usage question | [Discussions Q&A](https://github.com/xin-yi33/RxyCode/discussions/new?category=q-a) |
| Feature idea | [Discussions Ideas](https://github.com/xin-yi33/RxyCode/discussions/new?category=ideas) |
| Something you built | [Show and tell](https://github.com/xin-yi33/RxyCode/discussions/new?category=show-and-tell) |
| Reproducible bug | [Bug issue](https://github.com/xin-yi33/RxyCode/issues/new?template=bug.yml) |
| Agreed feature to track | [Feature issue](https://github.com/xin-yi33/RxyCode/issues/new?template=feature.yml) |
| Browse the forum | [Discussions](https://github.com/xin-yi33/RxyCode/discussions) |

How an ordinary developer enables the same forum on their own repository: [docs/community.md](docs/community.md) · [中文](docs/community.zh-CN.md).
